# 云想游戏厅 · YUNXIANG ARCADE

> 本游戏厅由 **DeepSeek-V4-Flash-0731** 制作。
>
> ⚠️ **仅供学习交流,非商业用途。** 所有像素美术、音效与代码均为原创,玩法机制向经典游戏致敬。请勿在商业项目中使用本仓库的任何素材。

童年游戏一盒装:一个网页,一个主菜单,插上卡带就能玩。纯 HTML5/Canvas,零外部依赖(音效用 Web Audio 实时合成),手机触摸与桌面键盘均可游玩。

## 快速开始

```bash
# 本地预览(任意静态服务器均可)
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 操作说明

### 蘑菇勇者(横版)
| 操作 | 键盘 | 触摸 |
| --- | --- | --- |
| 移动 | ← → | 屏幕左下按钮 |
| 加速 | Shift | B 键 |
| 跳跃 | Z / 空格 | A 键 |

### 钢铁前线(坦克)
| 操作 | 键盘 | 触摸 |
| --- | --- | --- |
| 移动/转向 | ↑ ↓ ← →(或 WASD) | 十字方向键 |
| 射击 | J / Enter | 开火按钮 |

## 目录结构

```
index.html            游戏厅主菜单(卡带墙)
js/platform.js        平台壳:游戏注册与生命周期
js/audio.js           共享音效合成(Web Audio)
js/input.js           共享输入(键盘+触摸)
games/mario/          蘑菇勇者(横版)
games/tank/           钢铁前线(坦克大战轻量版)
test/                 冒烟测试
```

## 技术备注

- 每个游戏是独立 HTML 页面(iframe 隔离),注册进平台后由主菜单调度
- 游戏物理/渲染基于 Canvas 2D 像素画,固定 60Hz 步进
- 全部像素美术与音效为原创,玩法机制不受版权保护,但请勿使用原版名称与素材
