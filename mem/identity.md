# 项目身份与编年史

## 我是谁

这个仓库是"云想游戏厅"——一个纯 HTML5/Canvas 的复古游戏合集,由 DeepSeek-V4-Flash-0731 与用户协作完成(README 署名)。它是 AI 家族史:每一代会话通过 CLAUDE.md + mem/ 继承记忆,保持人格一致。**游戏厅的一切素材都是原创的,这是一个刻意且重要的决策**(见下)。

## 编年史(2026-08-02,一天走完的路)

1. **接手**:项目最初是一堆 bug 的 HTML5 马里奥复刻(碰撞渲染错位 32px、踩敌人自己也死、隐形障碍、角色浮空)。
2. **修 bug 大战**:定位渲染/碰撞偏移、踩敌判定、踢壳反杀、相机单向、触摸按钮、字体缺失等一串问题,`node test/smoke.js` 16 项回归全绿。
3. **部署**:仓库推到 GitHub 大号 `xingyejiu237/game_demo1`,开 Pages,绑域名 `yunxiangcity.top`(DNS 在 Cloudflare),踩了私有仓库/橙云代理/证书 errored 的坑。
4. **转型游戏厅**:用户提出"童年游戏机"概念 → 平台壳(卡带墙 + iframe 生命周期)+ 马里奥换皮为"蘑菇勇者"。
5. **三张卡带**:钢铁前线(坦克,踩了 60 倍冷却/敌人不开火的坑)→ 爆破小子(炸弹人,敌人 AI 重做两轮:先会躲雷,再会进攻+逃生规划)。
6. **打磨**:触摸按钮响应式、favicon、6 格卡带墙、CLAUDE.md + mem/ 记忆架构。

## 关键决策与原因(后人不要推翻,除非有充分理由)

- **全力换皮、素材原创**:用户明确怕被告赔钱。玩法机制不受版权保护,但原版名称/美术/音乐是雷区。任何可见位置(含代码注释)不得出现原版名称。
- **iframe 游戏隔离**:每个游戏自包含目录,互不干扰,新游戏零风险接入。共享层只有 input/audio。
- **共享 input.js**:键位语义多游戏共存(↑/W = 跳跃+上移,空格/Z = 跳跃+射击),改前必须验证全部游戏。
- **测试驱动**:冒烟测试(fake canvas + 注入 actions)是"看起来没事其实完全坏掉"类 bug 的最后防线(敌人不开火就是靠它抓出来的)。
- **节奏**:用户实测玩法,反馈 bug,我修。不搞冗长的自动化验证。
